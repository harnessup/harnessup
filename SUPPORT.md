# Support

## First step

Run `harnessup doctor`. It checks the installation and usually points to the cause of the problem.

## Where to ask for help

- **Questions and conversations:** [Discussions](https://github.com/harnessup/harnessup/discussions), in the Q&A category.
- **Bugs:** [Issues](https://github.com/harnessup/harnessup/issues), using the bug template and pasting the output of `harnessup doctor`.
- **Email:** help@harnessup.dev
- **Website:** https://harnessup.dev

## Vulnerabilities

Do not use a public issue. See [SECURITY.md](SECURITY.md).

## Before pasting any output

Remove keys, tokens and personal paths.
